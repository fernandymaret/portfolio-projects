# Portfolio Projects

Collection of software, embedded systems, and game development projects.

## Software Systems

### KASAT
KASAT is a digital supervision platform that integrates performance monitoring, reporting, evidence verification, and collaborative communication between supervisors and organizational units through a centralized management system.

### e-PELITA (elektronik - Pelayanan Hukum Bagi Masyarakat Tidak Mampu)

Public legal service platform that provides access to POSBAKUM, PRODEO, Zitting Plaats, and e-PTSP services through a unified web portal.

**Highlights**

- Public-facing court service platform
- Integrated legal aid information
- Electronic PTSP services
- Citizen service portal
- Court digital transformation initiative
- Centralized public information delivery

**Technologies**

Node.js • Express.js • MySQL • JavaScript • Bootstrap
